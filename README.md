# Independent QA Lab

Independent QA Lab is an experimental, standalone quality-assurance platform.

## Boundaries
- The technical hospital owns cases, decisions, and closure.
- QA Lab executes approved tests and returns evidence; it does not merge or deploy production changes.
- AI suggestions are advisory and must pass independent tests.

## Status
Public bootstrap only. Source import, Docker services, secrets review, provenance and live Railway acceptance are pending. No historical laboratory source or secrets are published in this initial commit.
