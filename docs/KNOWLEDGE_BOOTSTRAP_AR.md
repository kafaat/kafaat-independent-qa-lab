# خدمة المعرفة المستقلة — حزمة وثائق عامة مقيدة بالمصدر

هذه المرحلة تضيف **خدمة بحث استشهادية تجريبية**، وليس نموذج ذكاء اصطناعي توليدي. تتضمن صورتها ثلاث وثائق هندسية عامة محددة من جذر المستودع. يجري التحقق من SHA-1 بصيغة Git blob لكل وثيقة قبل الفهرسة، ثم حفظ SHA-256 للنص والأجزاء.

تُنشئ `qa_lab.knowledge_seed` فهرس SQLite خلال بناء صورة Docker من `Dockerfile.knowledge`. يُثبت الفهرس كملف للقراءة فقط، وتستخدم الخدمة `sqlite mode=ro` وتتحقق من اكتمال الوثائق المثبتة قبل قبول الطلبات. لا توجد واجهة استيراد عبر HTTP، ولا تنزيل نموذج أو اتصال خارجي، ولا يسمح بإضافة مصادر خاصة تلقائيًا.

تتطلب الخدمة `QA_KNOWLEDGE_TOKEN` سرًا مستقلًا طويلًا، ويجب إبقاء الشبكة خاصة دون نطاق عام. توفر `/v1/search` و`/v1/answer` مقتطفات مع مرجع مصدر مثبت، وترفض الطلبات غير المصرح بها، ولا تعطي حكمًا على نجاح الاختبارات أو الدمج أو الاعتماد الإنتاجي.

## التحقق

- فحص manifest للتكرارات وحقولها والوثائق المسموحة ومساراتها ومنع الروابط الرمزية.
- رفض أي اختلاف بين Git blob SHA والملف الموجود في شجرة البناء.
- فشل مبكر عند نقص المصدر أو كبره أو عدم صلاحيته للترميز.
- تحقق من الإقلاع الفعلي لصورة Docker في GitHub CI بوضع `--read-only` وبمستخدم غير جذر.
- فحص رفض الطلبات غير المصرح بها واسترجاع مقتطفات مربوطة بالمصدر والامتناع عند غياب الأدلة.

## حدود القبول

لا توجد بيانات سرية أو وثائق المختبر القديم ضمن هذه الحزمة. لا يوجد نموذج embedding مثبت أو LLM، ولا اختبار دقة على corpus كبير أو هوية مضيف موقعة أو ACL على مستوى المستخدم. Git blob SHA يثبت تطابق المحتوى فقط وليس ملكيته أو مصدره المؤسسي. لا تعتبر الخدمة جاهزة للإنتاج ولا تثبت التكافؤ الوظيفي الكامل.
