# Legacy Unified Local Lab parity gate

The original imported laboratory source remains outside this public repository pending provenance, license and secret review. The current PostgreSQL service supports only a fixed python-smoke recipe; it is not functionally equivalent to Unified Local Lab.

## Required inventory and evidence
- Enumerate original CLI commands, adapters, test recipes, expected outputs and required runtime dependencies.
- Pin legacy source tree hash and new source tree hash.
- For each supported capability, run both versions with identical sanitized inputs and capture receipts.
- Mark results VERIFIED, PARTIAL, FAILED, or NOT_RUN; missing data must not become PASS.
- Require separate approval for migration of security-sensitive artifacts and private fixtures.
- Do not retire the original engine until all mandatory parity scenarios pass.
