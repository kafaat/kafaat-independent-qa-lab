# قرار حوكمة — إلغاء إلزام المراجعة البشرية (2026-11-01)

**الجهة:** مالك مستودع kafaat/kafaat-independent-qa-lab بطلب صريح في محادثة المتابعة.

**النطاق:** مختبر QA محلي لإنتاج أدلة تنفيذ الاختبارات، وليس منصة عامة متعددة المستخدمين.

## القرار

- إلغاء اشتراط موافقة بشرية مستقلة قبل دمج Pull Requests بصورة دائمة ضمن السياسة الحالية للمختبر.
- إلغاء اشتراط التدقيق الأمني والوظيفي البشري الرجعي لـ PR #44 بوصفه شرطًا إلزاميًا للحوكمة أو إغلاق القضية #46.
- تبقى المراجعات البشرية اختيارية عند ارتفاع المخاطر أو رغبة مالك المستودع، ولا يجوز نسبتها إلى أي شخص دون مراجعة حقيقية موثقة.
- تظل متطلبات CI الأربعة، والحماية من الحذف والدفع القسري، والاستهداف الحصري لفرع main، وعدم وجود Bypass، إلزامية.
- تسمى المتطلبات الملغاة **WAIVED BY OWNER DECISION** لا **PASSED**؛ لا نصطنع موافقة مراجع أو اختبارًا لم يقع.
- لا يمثّل هذا القرار ترخيصًا بالنشر الإنتاجي أو العام أو بالدمج التلقائي.

## الأدلة الأساسية

- Ruleset الحية بتاريخ اتخاذ القرار: https://github.com/kafaat/kafaat-independent-qa-lab/rules/26292547
- الحالة المثبتة: Active، refs/heads/main، عدد الموافقات الإلزامية صفر، بلا استثناءات.
- Checks: test وoperator-ui وroot-stack وhttp-stack، كلها من GitHub Actions App ID 15368.
- PR #44: https://github.com/kafaat/kafaat-independent-qa-lab/pull/44 — يظل تاريخ التنفيذ والاختبارات قائمًا، ولا يدّعي القرار وجود تدقيق بشري رجعي.
- PR #48: https://github.com/kafaat/kafaat-independent-qa-lab/pull/48 — أدوات الحوكمة المدمجة لا تمثل شهادة أمنية لواجهة PR #44.
- Issue #46: https://github.com/kafaat/kafaat-independent-qa-lab/issues/46 — يجب أن يذكر السجل التاريخي إلغاء الشرط لا إنجازه.

## حدود المخاطر

تظل واجهة المشغّل محلية على 127.0.0.1، مع عدم توفر حسابات متعددة أو RBAC أو قبول لبوابة HTTPS عامة أو اختبار استعادة إنتاجية. لا يجوز اعتبار نجاح الاختبارات الآلية تصديقًا أمنيًا مستقلًا أو قبولًا إنتاجيًا. يمكن إجراء فحص بشري اختياري لاحقًا عند ظهور مخاطر جديدة.

## التحقق التقني المتبقي

يُستحسن تنفيذ PR اصطناعي منفصل لإثبات أن GitHub يمنع الدمج عند فشل أو غياب أي فحص إلزامي، دون دمج الاختبار أو نشر أي خدمة. هذا فحص تقني مستقل عن المراجعة البشرية. تغيير ملفات JSON وحده لا يفعّل أي تعديل على GitHub Settings؛ يجب التحقق من القواعد الحية عبر API.
